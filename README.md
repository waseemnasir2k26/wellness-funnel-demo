# wellness-funnel-demo

A Next.js demo lead funnel for a wellness coaching brand ("Phoenix Wellness") — landing page, quiz, guide, programme, reset and booking routes — built by SkynetLabs as a portfolio and pitch piece.

## Status

Last reviewed: September 2026 · release v2026.09

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · ESLint 9

## Routes

| Route | Purpose |
|---|---|
| `/` | Landing page |
| `/quiz` | Lead-qualifying quiz |
| `/guide` | Lead-magnet guide |
| `/programme` | Programme detail |
| `/reset` | Reset offer page |
| `/book` | Booking step |

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```
