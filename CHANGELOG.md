## [2026.09] - 2026-09-16

- Maintenance review of `wellness-funnel-demo` — a Next.js demo lead funnel for a wellness coaching brand ("Phoenix Wellness"), built by SkynetLabs as a portfolio/pitch piece.
- Stack: Next.js 16.2.4 App Router with React 19, Tailwind CSS v4 (PostCSS plugin), TypeScript and ESLint 9. Five routes under `app/` — landing page plus `/quiz`, `/guide`, `/programme`, `/reset` and `/book` — with the vibrant terracotta/saffron/plum/mustard palette and SkynetLabs footer attribution added in the last commit (2026-04-26).
- Status: public repo, package version 0.1.0, private:true in `package.json`. Runs with `npm run dev` / `npm run build`; no live URL is stated in the repo.
- Reviewed September 2026: README replaced (it was still the untouched `create-next-app` boilerplate), package version bumped to 0.2.0, released as v2026.09. No route, component or styling changes.
- Known gaps visible in the repo: no CHANGELOG before this release, no LICENSE, no tests, and `public/` still carries only the default create-next-app SVGs (next, vercel, file, globe, window).
